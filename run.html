Run it, don’t just read it

The prototypes — public, and marked for how real they are.

Everything here is under github.com/MIRA-science and public. Each entry says what it is, the one link, and what to try — and carries an honest status, because this page is also the transparency evidence. We don’t oversell a link.

schemashipped

The canonical LinkML grammar — every node and edge on this site is defined in it. SHACL, Turtle and JSON-LD are generated from the source.

What to try: read mira.yaml, then run the Makefile to regenerate SHACL and validate a graph against it.

The DNA walkthroughshipped

The interactive schema-demo deck: the six-node grammar built one record at a time on the discovery of DNA’s structure, with every slot and edge explaining itself on hover.

What to try: scroll it end to end, then hover an edge label to read the relation both ways.

MIRA-extractionshipped

AI-assisted MIRAfication of a source. Emits a verbatim provenance.excerpt for each node (the receipts), reports dangling and ungrammatical edges instead of dropping them, and enforces the source → study → grounds → evidence spine.

What to try: MIRAfy a source and diff the Initial AI draft nodes against what a human would advance — the diff is the exhibit.

demo-MIRA-graph-datashipped · mock data

A ~314-node discourse graph plus a standalone d3 viewer and the Python transform pipeline that built it. The data is mock — terms are randomized to a microtubule-transport field; use it to validate tooling, never as a scientific source.

What to try: open the d3 viewer and traverse from a Question to its Evidence; the same grammar, rendered and navigable.

myst-plus-mirashipped

The TypeScript MyST parser — authoring discourse-graph nodes inside MyST Markdown and emitting JSON-LD. One authoring tool to one viewer: real, and narrow.

What to try: npm test (vitest) — the MyST → JSON-LD round-trip on the golden fixture.

koi-net-mira-prototypepast-tense pilot

The KOI cross-organization envelope. During the inter-lab pilot, different people’s agents and tools read from and wrote to the same KOI node across organizational boundaries, routinely. We do not claim a live federated network today.

What to try: run the local prototype network (toy-demo) and watch the coordinator-as-discovery 56-record lossless round trip.

The shape of it

Many tools, one graph.

Authoring tools and viewers all speak JSON-LD to one shared graph. The two graphs at the bottom are live and public — the same grammar running on two unrelated fields, as real instances.

MIRA is an open schema. MIRA hosts nothing. Every record here points at a public artifact.
Private repositories are never cited here. What is not yet built, and the gaps we’re tracking, are laid out in the Context and caveats.
